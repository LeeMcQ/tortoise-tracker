# Expert Review Cycle 2 — Conservation Science, GIS & Public Experience

Date: 2026-08-13

## Panel input

### Conservation-security specialist
- Generalisation alone is not sufficient reason to draw public movement tracks. Connecting sequential public points can create an implied route and can still reveal spatial preferences.
- Public history should default to points/areas only; connecting lines should be disabled in the public interface.
- Do not show research GPS accuracy to anonymous visitors; show that the location is intentionally generalised instead.

### Movement ecologist / GIS specialist
- Retain chronology and an accessible list, but phrase it as an observation history rather than a travelled path.
- Add a public directory/search function so visitors can find animals without needing to know an ID.
- Surface taxon conservation information when available, without exposing restricted ecological data.

### Visual/product designer
- Replace emoji-only animal imagery with a proper image slot and a branded offline-safe fallback illustration.
- Make the animal profile the emotional centre of the public experience while preserving scientific restraint.

### Citizen-science / behavioural design specialist
- On confirmation, show a friendly record-quality band rather than a numerical score that may feel like the visitor is being graded.
- Keep numerical quality scoring restricted to staff/research workflows.

### Language/content specialist
- Remove remaining English-only public headings and status messages.
- Public-facing routes must be fully English/Afrikaans from the central translation dictionary.

## Implementation decision
All findings accepted for Cycle 2.
